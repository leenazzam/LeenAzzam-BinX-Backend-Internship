#  Day 1 — REST API Design Principles

Learned REST conventions for designing APIs resources as plural nouns, HTTP verbs for actions instead of verbs in the URL, and correct status codes for each outcome (200, 201, 204, 400, 404).

Completed the hands-on lab: designed a resource map for a Task Tracker API (Tasks and Projects), with full CRUD endpoints for Tasks, one nested endpoint for a project's tasks, and a versioning convention using /api/v1.
