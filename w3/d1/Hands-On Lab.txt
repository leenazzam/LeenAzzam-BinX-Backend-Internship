Domain: Task Tracker

GET    /api/tasks           → list all tasks         → 200 OK
GET    /api/tasks/{id}      → get one task            → 200 OK / 404 Not Found
POST   /api/tasks           → create a task            → 201 Created
PUT    /api/tasks/{id}      → update a task            → 200 OK / 404 Not Found
DELETE /api/tasks/{id}      → delete a task            → 204 No Content / 404 Not Found

----------------------

GET /api/projects/{id}/tasks   → all tasks belonging to a specific project   → 200 OK / 404 Not Found

-----------------------

POST /api/tasks   with missing "title" field   → 400 Bad Request
