## Day 2 Summary

In Day 2, I implemented JWT authentication and login using ASP.NET Core Identity. I created a login endpoint that verifies user credentials, generates a signed JWT containing the user ID and email, and sets a 15-minute expiration time. I also configured JWT Bearer Authentication and tested the generated token using Postman and jwt.io.
